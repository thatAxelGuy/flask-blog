# Flask Blog

A simple Flask blog application for creating, updating, deleting, and liking blog posts.

## Installation

Install the required dependencies using `requirements.txt`:

```bash
pip install -r requirements.txt
```

## Using uv

If you use [uv](https://docs.astral.sh/uv/), you can install the project dependencies with:

```bash
uv sync
```

Run the application with:

```bash
uv run python app.py
```

## Run the Application

If you installed the dependencies with pip:

```bash
python app.py
```

Then open `http://localhost:5000` in your browser.

## Features

* View blog posts
* Add blog posts
* Update blog posts
* Delete blog posts
* Like blog posts
